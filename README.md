# Servifide demo

As an organization grows, it gets harder to answer basic questions: Which services do we use? Who provides them? Which agreement covers them? Who owns the work when something is missing? Servifide brings those answers together so leaders can see where a decision or follow-up is needed.

This public gallery shows the workflow with fictional records, people, and organizations. The working application and its source stay private. This repository contains screenshots, not a live demo.

## Start with the Policy register

The register shows who owns a policy, which version is approved, when it is due for review, and which source and evidence references support it. The retained history shows who submitted and approved the version and why.

![Policy register showing the current approved version, accountable owner, review date, and version history](assets/servifide-policy-register.png)

## Find the records behind a decision

Search narrows the inventory to the records you need. This example finds services used for quarterly access reviews and shows an export of the results.

![Workspace search showing three fictional quarterly access services and a CSV export panel](assets/servifide-search-csv-export.png)
