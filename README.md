# Servifide

**A synthetic-data demo for policy review and security-operations search.**

Servifide explores how a team can govern policy changes and find service context while keeping source material, review, and accepted decisions distinct.

## Versioned policy review

Create a policy with an accountable owner and retained source and evidence references. Submit a version to a different active administrator for approval or return; inspect its history and retire the policy when it is no longer active. Approved versions and their linked evidence references cannot be rewritten.

## Scoped search and CSV export

Search organizations, services, agreements, controls, risks, assessments, and Work. Filter results and navigate stable pages. Download the full authorized query and filter as CSV, up to 500 rows.

## Product principles

- Source and evidence references do not themselves prove or approve a policy.
- Workspace permissions govern search and exports.
- A distinct administrator decides whether a version is approved.

## Demo boundaries

This showcase uses synthetic data. It is not a live deployment, compliance certification, or evidence of production readiness.
